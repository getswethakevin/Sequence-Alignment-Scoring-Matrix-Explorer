# Sequence Alignment Scoring Matrix Explorer

An interactive web application for performing global sequence alignment using the Needleman-Wunsch algorithm.

## Features

- Enter two biological sequences.
- Customize match, mismatch and gap scores.
- Generate a scoring matrix.
- Generate a traceback matrix with directional arrows.
- Display the final aligned sequences.
- Calculate the optimal global alignment score.

## Technologies Used

- Python
- NumPy
- Pandas
- Streamlit

## Algorithm

Needleman-Wunsch Algorithm (Dynamic Programming).

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Run the following command:

```bash
streamlit run app.py
```

The application will open in your web browser.
